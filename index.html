STUDENT GUIDE

How to use the SQL Mastery Lab

  1. Select a level from the roadmap.
  2. Read the challenge and identify the required SQL concept.
  3. Write your query in the editor and click Run Query.
  4. Use Check Answer when you are ready.
  5. Use Hint before Show Solution whenever possible.
  6. Completed question numbers turn green. Progress syncs to your student account and is also cached in this browser.
Important: The practice engine runs SQL in your browser using sql.js. It is a learning sandbox; it is not a connection to your production MySQL server.
